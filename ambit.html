Ambit

A permissions library for AI agents — deny always wins

Without ambit, a hallucinating model can call delete_database, send_email, or any other tool in its registry — the only limit is what was registered. With ambit, a plain YAML file is the limit.

npm install agent-ambit

How it works

Ambit wraps a tool registry and checks every call against a policy before the underlying function runs, regardless of which client or model is driving the agent:

import { wrap } from "agent-ambit";

const guard = wrap(myTools, { policy: "policy.yaml" });

// Blocked calls throw PermissionDeniedError with instructions for the fix.
// Allowed calls pass through to the original function unchanged.
const result = await guard.call("read_file", { path: "/tmp/data.csv" });

A policy is one readable file, not code scattered through the tool implementations:

# policy.yaml
tier: operator        # readonly | operator | admin

# operator allows all tools by default.
# List only the tools you want to restrict.
deny:
  - delete_file
  - filesystem:write_file   # scoped to the "filesystem" MCP server only
  - run_shell               # applies to all servers (no prefix)

readonly denies everything by default and asks you to opt tools into allow. operator allows everything except tools that read as destructive by name — delete_file, dropTable, purge_cache — unless you explicitly allow them. admin allows everything, including destructive-sounding tools, with no built-in carve-out. Across all three, a tool listed in both allow and deny is denied — deny always wins.

What it does and doesn't protect against

Defends against: a hallucinating or prompt-injected model calling tools it shouldn't. The check happens server-side, before the tool function runs.

Does not defend against:

  • A fully compromised process — ambit is not a sandbox. If the runtime itself is compromised, the check can be bypassed.
  • Parameter-level misuse of an authorized tool — ambit controls which tools are called, not what arguments they receive.
  • A malicious server you chose to wrap — ambit enforces your policy against your registry, not against the registry's own intentions.
